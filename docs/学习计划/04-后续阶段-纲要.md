# 后续阶段纲要（D–G）

> 这一份是**纲要**，不是清单。原因很实际：你完成 A–C 之后水平会明显不同，现在写细了到时候要重写。
> 到期时我把对应阶段展开成和 A/B/C 一样的详细版。

## 阶段 D · Python 与 FastAPI（4 周）→ 项目 P2

### 学什么

| 周 | 内容 | 学到什么程度 |
|---|---|---|
| 1 | Python 语法：变量、字符串、list/dict、`for`、函数、`if __name__ == '__main__'` | 能写出 50 行脚本并跑通 |
| 1 | 类型注解：`def f(x: int) -> str:` | 知道注解不强制、但能给编辑器提示 |
| 2 | 类与对象、模块与包、`venv` / `uv`、`pip install` | 会自己建环境装依赖，不污染系统 Python |
| 2 | 异常处理 `try/except`、文件读写、`pathlib` | 能读一个 JSON 文件并处理缺失字段 |
| 3 | **FastAPI 基础**：路由、路径参数、查询参数、请求体、Pydantic 模型 | 能写 5 个接口并在 `/docs` 里点通 |
| 3 | 依赖注入 `Depends`、异常处理、中间件 | 能写一个"取当前用户"的依赖 |
| 4 | 异步 `async/await`（先理解"为什么 Web 服务要异步"）、`uvicorn` 启服务 | 能解释同步阻塞会让第二个请求排队 |

**资源**：Python 官方中文教程（`docs.python.org/zh-cn/3/tutorial/`）+ FastAPI 官方中文文档（`fastapi.tiangolo.com/zh/`，它的「教程 - 用户指南」就是最好的教材）。

### 项目产出（P2）

| 产出 | 判据 |
|---|---|
| `api/app/main.py`，`GET /api/healthz` 返回 `{"ok": true}` | `curl` 通 |
| systemd 单元，进程被杀 3 秒后自动重启 | `systemctl status` 显示 active，手动 `kill` 后自动恢复 |
| 云上 nginx 把 `/api/` 反代到 `100.64.0.35:8000` | `https://new.justinemils.top/api/healthz` 通 |
| 一个假数据接口 `/api/services` | 返回写死的 3 个服务 |

## 阶段 E · SQL、账号与权限（5 周）→ 项目 P3 / P4

### 学什么

| 周 | 内容 |
|---|---|
| 1 | SQL 基础：`SELECT / WHERE / ORDER BY / INSERT / UPDATE / DELETE / JOIN / 索引`。练习用 SQLBolt 或 `sqlite3` 命令行 |
| 2 | SQLAlchemy 2.0：声明式模型、`select()`、关系、异步 session；Alembic 迁移 |
| 3 | 密码与认证：哈希为什么不能可逆、argon2、cookie 与 session、TOTP（`pyotp`） |
| 4 | 权限：角色、ACL 表、依赖注入里做鉴权、`403` 与 `401` 的区别 |
| 4 | 邮箱验证与找回密码：一次性 token、有效期、SMTP 发信 |
| 5 | Nginx `auth_request`：让网关在反代前先问后端"这人有没有权限" |

### 项目产出（P3 / P4）

| 产出 | 判据 |
|---|---|
| 用户表 + 会话表 + 角色表 | 迁移能正向跑也能回滚 |
| 注册 + 邮箱验证 + 登录 + TOTP + 找回密码 | 全流程走通；验证链接只能用一次 |
| 逐服务 ACL | 不同角色看到不同服务清单 |
| 网关拦截 | **不登录直接访问内网服务地址被挡住** |
| 7 条主链路的 pytest | `pytest` 全绿 |

⚠️ 这是整个计划里**最难的一段**。兜底方案：先只做"邀请开号"（不接邮件），把登录与权限跑通，再加自助注册。

## 阶段 F · 部署与运维（3 周）→ 项目 P5 / P8 的一部分

### 学什么

| 内容 | 学到什么程度 |
|---|---|
| Linux：进程、端口、权限、磁盘、日志、`systemd` / `journalctl` | 能排查"服务为什么起不来" |
| Nginx：server 块、反代、静态缓存头、gzip/brotli、CSP | 能自己加一个子域 |
| 备份与恢复 | **做一次真实的恢复演练**：删库 → 从备份还原 |
| git 分支与合并 | 能开分支做实验、能处理一次冲突 |
| 监控自身 | 备份失败要在控制台首页亮红 |

### 项目产出

一键发版脚本、每日自动备份、只读监控页、预设动作按钮 + 审计日志。

## 阶段 G · Three.js 与 WebGL（5 周）→ 项目 P9

### 学什么

| 周 | 内容 |
|---|---|
| 1 | 核心概念：场景 / 相机 / 渲染器 / 坐标系 / 循环；加载一个 glTF 模型 |
| 2 | 几何与材质、光照（环境光 + 平行光 + 点光）、阴影 |
| 3 | 交互：射线拾取（点击物件）、OrbitControls 的限制用法、相机动画（`lerp`） |
| 4 | 性能：纹理压缩（KTX2）、draw call、`renderer.info`、像素比上限 |
| 5 | **资源释放**：`dispose()`、`setAnimationLoop(null)`、React 集成（`useEffect` 里建、清理里拆） |

**资源**：Three.js 官方手册中文版（`threejs.org/manual/zh/`）+ 官方 examples。

### 项目产出

把 `manifest.renderer` 从 `still` 改成 `webgl`，书房变成实时场景；**DOM 卡片、锚点数据、路由一行不动**。

判据：

- 关掉 WebGL 后网站仍然完整可用（降级到静帧）
- 切走页面后没有 WebGL context 泄漏（DevTools 里 context 数量不增长）
- 移动端不加载 3D chunk

## 阶段 H（可选）· agent 能力

你实习方向的加分项。前提是本地 2×V100 可用。

| 内容 | 产出 |
|---|---|
| LLM API / 本地模型（vLLM 或 Ollama） | 一个能回答"最近服务器怎么了"的只读助手 |
| 工具调用（function calling） | 只读工具集：查文章、查监控、查服务 |
| 提示词与输出约束 | 结构化输出能被后端校验 |

**铁律**：模型只能调只读工具；任何写操作必须渲染成待确认表单，由人点。
