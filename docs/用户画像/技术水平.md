## 2. 作者亲自修正的三条（2026-11-23）

这三条是原假设**高估**的地方，后续所有教学安排以此为基准：

| 原假设 | 实际 | 对计划的影响 |
|---|---|---|
| TypeScript "类型注解大概知道，接口/泛型没见过" | **连类型注解是什么都不知道** | 阶段 A 第 1 周必须从"给变量标类型是什么意思"讲起，不能跳 P15–P27 |
| JavaScript "能读懂，从零写会卡" | 还要加一条：**不知道怎么把 JS 接到 HTML/框架上** | 阶段 A 第 2 周（DOM）是真正的瓶颈，练习要覆盖"数据 → DOM → 事件"完整链路 |
| CSS "熟悉" | 会写但**很丑、易出错、不知道错在哪** | 需要额外的"CSS 排错与判断好坏"微模块：DevTools 布局排查、盒模型、常见塌陷/溢出、对比度与间距判据 |

其余七条（React 概念级、Python 零、命令行基础、git 基础、SQL 零、每周 10 小时、视频优先）**确认准确**。

## 3. 能力缺口的正确顺序

按"卡住项目的先后"排，不是按教科书顺序：

| 优先 | 缺口 | 不补会卡在哪 |
|---|---|---|
| 1 | JS 基础语法 + 断点调试 | 一切 |
| 2 | **JS → DOM 的桥**（数据怎么变成界面） | 首页卡片、列表、任何交互 |
| 3 | TS 类型注解与接口 | 场景 manifest、接口数据 |
| 4 | React 状态与渲染 | 首页原型 |
| 5 | CSS 排错的肌肉记忆 | 页面调不出来就卡死 |
| 6 | Python 语法与虚拟环境 | 后端一行都写不了 |
| 7 | SQL 与 ORM | 存不了数据 |
| 8 | 认证与权限 | 多用户需求做不了 |
| 9 | Linux/nginx/systemd | 上不了线 |
| 10 | Three.js | 只是"升级"，不影响上线 |
