# 目标与动机

> 最后更新：2026-11-23

---

## 1. 这个项目是什么

对外是**一个私人图书馆式的个人站**：进门是书房，书架是博客，各房间是自建服务，还有一整套账号与权限。
对内是**一次完整的全栈练手**：从 CSS 到手写权限网关，每一块自己写、自己排错。

原话："这个网站应该同时实现记录和名片的功能……作为我开发的服务的门户页，并且在通过网站管理我的服务器。"

---

## 2. 真正的目标（优先级从高到低）

| 优先 | 目标 | 判据 |
|---|---|---|
| 1 | **备战明年的 agent 全栈开发实习** | 能讲清这个项目的每一层，能现场改代码 |
| 2 | 学会开发（不是"上线一个站"） | 每一块自己写、自己排错，不整体照抄模板 |
| 3 | 日常可用 | 自己每天真的会打开它：看服务、发文章、开号给朋友 |
| 4 | 视觉表达 | 做出"温暖书房"这个具体构想，而不是通用模板站 |

**注意优先级**：如果某天要在"更快上线"和"自己写一遍"之间选，选后者。这不是产品项目。

---

## 3. 时间线

| 时间 | 目标 |
|---|---|
| 2026-11 ～ 2027-02 | 阶段 A–C：前端地基 + 首页原型 + 部署到子域 |
| 2027-03 ～ 2027-06 | 阶段 D–F：后端、账号权限、部署运维 |
| 2027 暑期 | 投递实习；此时项目应有：公网站点 + 博客 + 多用户登录 + 服务门户 + 监控 |
| 之后 | 阶段 G（Three.js）+ 阶段 H（agent 能力）作为加分项 |

⚠️ **实习时间点倒推**：如果 2027 年 3 月要投简历，那么"能拿出手的最小版本"必须在 2027 年 2 月前完成——也就是 **A–C 三个阶段 + P0/P1**。所以优先级是"先把能看的做出来"，而不是"先学完再做"。

## 5. 不追求什么

| 不追求 | 理由 |
|---|---|
| 上线即完美 | 这是学习项目，允许丑、允许改 |
| 用户量 / 增长 | 不是产品 |
| 技术栈新颖 | 稳定、能学会、面试能讲清 > 新 |
| 一次做完 | 25 周的计划，急着做完等于什么都学不到 |
